Gllia, le launcher des patchs de traduction de la team Saint Eresia, en Rust avec
[egui](https://github.com/emilk/egui) (via `eframe`):

- La liste de nos patchs, à jour avec le site : illustration, avancement et lien vers la fiche de chaque jeu.
- Détection automatique des jeux installés sur Steam et GOG.
- Installation du patch en un clic, directement dans le dossier du jeu.
- Le bouton « Télécharger via Gllia » des fiches du site ouvre le launcher sur le bon jeu.
- Mode clair, sombre ou selon Windows.
- La page « À propos » présente l'équipe.

# Installation

Téléchargez Gllia.exe ci-dessous et lancez-le, il n'y a rien d'autre à installer (Windows 10 et 11).
Windows peut afficher « Windows a protégé votre ordinateur », car l'exe n'est pas signé : cliquez sur Informations complémentaires, puis Exécuter quand même.
